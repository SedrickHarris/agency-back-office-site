# Audience + Service Matrix

## Purpose

The matrix identifies strategically useful audience + service combinations.

A theoretical 15 × 15 matrix creates 225 combinations, but publication must be selective.

## Publish Criteria

A matrix page should be approved only if:

- the audience has a distinct need for the service,
- search intent differs meaningfully,
- audience-specific examples can be written,
- the page can provide standalone value,
- the page has clear internal-link relationships,
- the page is not a doorway/thin programmatic page.

- audience-specific problem framing
- service relevance
- practical implementation examples
- mistakes common to that audience
- related training
