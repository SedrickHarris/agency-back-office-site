# Content Production Workflow

## Step 1 — Select Page

Confirm the page exists in the master page list or approve it before writing.

## Step 2 — Define Intent

Document:
- page type
- audience
- search intent
- primary topic
- secondary topics
- CTA
- parent and child relationships

## Step 3 — Research

Research:
- terminology
- current platform behavior
- relevant questions
- competitor gaps
- examples
- authoritative sources where needed

Separate verified facts from opinions.

## Step 4 — Build Content Brief

Include:
- URL
- title direction
- H1
- content sections
- questions to answer
- internal links
- schema
- visual needs
- CTA

## Step 5 — Draft

Write for usefulness first.

Use Agency Back Office voice:
- practical
- clear
- experienced
- instructional
- direct

## Step 6 — Search Optimization

Review:
- topic completeness
- intent match
- metadata
- headings
- entity clarity
- internal links
- direct answers
- FAQs
- cannibalization risk

## Step 7 — Build Handoff

Provide Claude Code:
- exact route
- exact approved copy
- component expectations
- metadata
- link destinations
- schema inputs
- visual requirements

## Step 8 — QA

Run the page through `qa-checklist.md`.

## Step 9 — Update Registry

Mark:
- status
- publication date
- canonical
- related pages
- future refresh date where appropriate
