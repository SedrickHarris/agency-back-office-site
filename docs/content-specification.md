# Content Specification

## Purpose

Define the minimum planning and content requirements for each page type.

## Universal Page Fields

Each indexable page should define:

- page name
- URL
- page type
- target audience
- primary topic
- primary intent
- title tag
- meta description
- H1
- canonical
- parent page
- internal-link targets
- primary CTA
- secondary CTA if needed
- schema recommendation
- image/visual requirements
- status

## Service Page

Recommended structure:

1. Hero/value proposition
2. Direct explanation of the training topic
3. Why the topic matters for agencies
4. What students should understand
5. Core areas covered
6. Implementation workflow
7. Common mistakes
8. Who this training is for
9. Related services
10. FAQs
11. CTA

## Audience Page

Recommended structure:

1. Audience-specific hero
2. Current challenges
3. What this audience needs to learn
4. Relevant Agency Back Office training areas
5. Common mistakes
6. Recommended learning path
7. Related resources
8. FAQs
9. CTA

## Audience + Service Page

Recommended structure:

1. Audience/service value proposition
2. Why this topic matters specifically to the audience
3. audience-specific use cases
4. workflows/examples
5. mistakes and gaps
6. what to learn
7. related training
8. resources
9. FAQs
10. CTA

## Resource Page

Must identify:
- parent topic
- target question
- direct answer
- detailed explanation
- implementation guidance
- related resources
- canonical service link
- next step

## Home Page

| Field | Value |
|---|---|
| URL | `/` |
| Page type | Core page, Phase 1, Critical |
| Primary intent | Navigational with some commercial investigation |
| Audience | Agency owners and new agency owners first |
| Title direction | "Agency Back Office \| Practical Digital Marketing and Agency Training" |
| Meta description direction | "Practical training in SEO, AEO, Google Business Profile, reputation management, automation, and agency operations for agency owners, marketers, and consultants." |
| H1 direction | "Practical digital marketing training for people who deliver client work" |
| Primary CTA | Explore the training (`/training/`) - pending confirmation |
| Secondary CTA | Get started (`/get-started/`) - pending confirmation |
| Schema | Organization, WebSite, WebPage |
| Status | Outline approved, copy not written |

### Section Order

1. Hero with a standalone one-sentence entity definition of Agency Back Office
2. Service topics index - two-column list grouped by theme, not a card grid
3. Learn / Build / Apply / Improve process diagram
4. Audience router ("Which describes you?")
5. Definitions strip - SEO, AEO, GBP, and Local SEO, each linking to its canonical service page
6. Training delivery
7. Free resources
8. Proof - conditional, verified items only; omit the section if none exist
9. FAQ of 4-6 questions
10. Closing CTA band

### Internal-Link Targets

- `/services/`
- `/audiences/`
- `/training/`
- `/resources/`
- priority service pages and priority audience pages (see `master-page-build-list.md`)
- `/about/`
- `/contact/`
- `/get-started/`

### Notes

- Include a visible "last reviewed" date on the definitions strip (see `aeo-ai-search-strategy.md`, Answer Block Standards).
- Do not invent proof, claims, pricing, or student counts.
- Define acronyms on first use (SEO, AEO, GBP).

## Writing Rules

- define acronyms on first use
- avoid filler introductions
- use plain language
- use examples
- do not keyword stuff
- do not fabricate claims
- use headings that communicate meaning
- prioritize usefulness over word count
