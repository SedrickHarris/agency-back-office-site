# Analytics and Measurement

## Objective

Measure acquisition, engagement, learning behavior, and conversion.

## Recommended Platforms

- Google Analytics 4
- Google Search Console
- Bing Webmaster Tools
- Cloudflare analytics as supplemental infrastructure data

Additional tools may be added only when they provide clear value.

## Core Events

Track:

- primary CTA click
- secondary CTA click
- contact form start
- contact form submit
- get-started action
- training enrollment/registration click
- resource download
- outbound platform click
- video start/completion where relevant
- scroll milestones only if useful

## SEO Measurement

Monitor:

- indexed pages
- impressions
- clicks
- CTR
- average position
- queries by service
- queries by audience
- non-brand vs brand traffic
- landing-page growth
- rich result performance where available

## Content Measurement

For resources:
- organic entrances
- engagement
- downstream CTA clicks
- assisted conversions
- internal-link navigation

## Conversion Measurement

Track conversion by:
- landing page
- page type
- service topic
- audience
- traffic source
- device

## Naming

Use consistent event naming, for example:

- `cta_primary_click`
- `cta_secondary_click`
- `contact_submit`
- `resource_download`
- `training_click`

Document event changes before implementation.
